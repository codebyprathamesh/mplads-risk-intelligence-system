# MPLADS Risk Intelligence System — V1
**Website link:**https://mplads-risk-intelligence-system.streamlit.app/

This folder contains the V1 application layer for the MPLADS Risk Intelligence System.

## Files
- `app.py` — Streamlit application
- `requirements.txt` — Python dependencies
- `.streamlit/config.toml` — Streamlit appearance and runtime configuration

## Dataset
The cleaned dataset is kept at `data/MPLAD_cleaned_v2.csv`.

## Run
From the repository root:
```bash
pip install -r v1/requirements.txt
streamlit run v1/app.py
```
